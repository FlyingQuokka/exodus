AI Bot Share: ten logo concepts

Blue-sky exercise. The placeholder face mark is ignored. Each mark is drawn from simple shapes so the chosen ones can be refined properly. The wordmark fonts load from Google Fonts. The light row shows the logo on white and the dark row shows it small on dark.

Name trademark and domain clearance is still open, so none of these should go public yet.
