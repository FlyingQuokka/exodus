CSS hooks for the theme

The first two screens are WordPress screens. Style them from login_enqueue_scripts.

  • body.login for the page background and fonts.
  • #loginform for the card (and #lostpasswordform on the forgotten password screen).
  • body.login h1 a for the logo link. Set its background image to the logo file and use the login_headerurl and login_headertext filters to point it at the home page.
  • .login #nav a for the forgotten password link and .wp-core-ui .button-primary for the button.

The help desk screen is the Fluent Support portal. Scope it inside #fluent_support_client_app.
