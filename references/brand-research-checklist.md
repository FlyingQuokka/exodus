# Brand Research Checklist — Portfolio Brands

A repeatable research pass for any brand added to this workspace as a **portfolio/practice brand**
(a real public company studied for creative-strategy practice, not a client). Run through this
list for each new brand before treating its foundation as ready to write from. Save the findings
into that brand's `state/brand-profile.md`, below the `exodus:auto-section-end` marker, under a
`## Research Notes (<date>)` heading — same pattern used for [iHerb](../iherb/state/brand-profile.md).

Not every item is a hard blocker — Genesis will run and produce reasonable output with just the
"Minimum to start" tier filled in. The rest sharpens portfolio-quality output.

---

## Minimum to start (foundation-blocking)

- [ ] **Positioning summary** — what they sell, who they target, core value proposition (source: About/homepage)
- [ ] **Trust & quality signals** — what the brand points to as proof (partnerships, guarantees, certifications, numbers)
- [ ] **Currently advertising? Where?** — check the [Meta Ad Library](https://www.facebook.com/ads/library/) (free, no login) for active campaigns
- [ ] **Recurring ad angles/formats** — pull patterns from what's actually live, not assumptions (educational, social-proof, offer-led, lifestyle, etc.) — group by apparent awareness level
- [ ] **Best-performing ads** — sort the Ad Library results by **Impressions: high to low** (a real Meta ranking signal, the closest public proxy to performance) and note the top 2–3, plus which ones show "N ads use this creative and text" — heavy variant reuse is a second, independent signal that a creative is converting well enough to keep scaling

## Deepen for portfolio-quality output

- [ ] **Hero products / SKUs with real pricing** — pull from the brand's own bestseller/catalog page, not third-party guesses. Anchors sample ads and emails in real offers instead of generic category talk.
- [ ] **Voice-of-customer language** — 4–6 short review snippets (Trustpilot, Google Reviews, Reddit) showing what customers actually praise and complain about, in their own words. Keep quotes brief and attributed — mine the *pattern*, don't reuse verbatim in output.
- [ ] **Overall trust gap check** — does public review sentiment reveal a specific weak point (support, shipping, etc.)? Useful for knowing which trust angles to lean into vs. avoid overselling.
- [ ] **Email marketing patterns** — search `milled.com` or similar public newsletter archives for real sent subject lines; note style (urgency, % off, holiday tie-ins, feature announcements, emoji use). **Note the limit honestly:** these archives show what was *sent*, not open/click/conversion data — there is no public way to identify a brand's best-*performing* email, only recurring patterns. Don't present frequency as if it were a performance ranking.
- [ ] **Visual style notes** — from ad creative actually running: product-forward vs. lifestyle-forward, background style, logo/brand-mark placement, color impressions. Zoom into static (non-video) ads specifically for a color/typography read if that level of detail is needed.
- [ ] **Competitor set** — who else shows up when searching the brand's category/keywords in the ad library or search results

## Explicitly out of scope for a portfolio brand

- Do **not** treat a real company's live ad copy as reusable "primer" text — pattern-match the *angle/format*, never lift the actual headline/body verbatim into generated output. Trademark/copyright risk, and it's not genuinely "this brand's" proven creative anyway.
- Do **not** represent portfolio-brand output as work done for or endorsed by that company. Label these brands clearly (in the profile notes, and to anyone the portfolio is shown to) as independent creative-strategy practice.

## Where to look, by item

| Info needed | Source |
|---|---|
| Positioning, value prop | Brand's own About/homepage |
| Active ad patterns | [Meta Ad Library](https://www.facebook.com/ads/library/) — search by brand name, filter Active status |
| Hero products/pricing | Brand's own bestseller/catalog page (may need a real browser, not a static fetch — many are JS-rendered) |
| Voice of customer | Trustpilot, Google Reviews, relevant subreddit/forum |
| Email patterns | [milled.com](https://milled.com), or search `"<brand>" email subject site:milled.com` |
| Visual style | Screenshot/zoom individual ads inside the Ad Library |
| Competitors | Ad Library search adjacent to the brand's category; "brand vs" search queries |
