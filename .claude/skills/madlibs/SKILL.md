# MADLIBS — Cross-Market Transposition

A winning ad asset is two things fused together. The **skeleton** — structure, rhythm, line breaks, escalation order, certainty level, the exact places the emotional beats land — is what testing and ad spend actually validated. The **payload** — the villain, the mechanism, the symptoms, the stats, the scenes, the charged words — is what aims it at one specific market. MADLIBS re-aims the weapon without re-engineering it: swap the payload vector by vector and touch nothing else. Every edit beyond the necessary swap is a chance to break something money already proved works.

So there are two rails, and every pass runs between them:

1. **Minimum changes.** If a line survives with one noun swapped, swap one noun. If it survives verbatim, keep it verbatim.
2. **Zero voltage loss.** The source's intensity was earned — it is the tested payload, not decoration. A swap that lands softer than the original is a failed swap even if it's accurate. The default model drift is toward sanitization; this process explicitly forbids it (see the Voltage Audit below).

Before writing a single transposed line, read the **Calibration** section at the bottom of this file — the canonical worked pass with before/after pairs and the sanitization counter-examples. If your output reads politer than the source, it is not done.

## What qualifies as a source asset

Hook primers, hook lists, complete long-form text ads, advertorials, email sequences, landing/sales-page sections — any proven text asset. If the user hands you an unproven draft to port, still run the process, but say the skeleton carries less authority than a tested winner's would.

## Inputs — gather, then go

1. **Source asset** (required) — the proven thing to transpose.
2. **Target market library** (required) — the target brand's winning ads, primer, brand profile, or product research, in whatever form the user has it (pasted text, a file, a doc). This library is your only parts bin: every stat, mechanism, coinage, and claim you swap in must exist in it. **Never fabricate a mechanism, study, number, or claim the target brand doesn't make.** A missing library is the one thing worth stopping to ask for.
3. **Steering notes** (optional) — anything the user wants held or avoided.

Do not interview. If both required inputs are present, run the entire pass and deliver. No menus, no "shall I proceed."

## The process

### 1. Inventory the target market

Read the target library FIRST — before x-raying the source — and extract its native vocabulary:

- **Villain(s)**: the named enemies (a hormone, an enzyme, a chemical, an institution)
- **Mechanism**: the brand's physics of the problem and cure, including branded coinages — always prefer the brand's own coinage over one you'd invent
- **Hard numbers**: every stat with a figure attached (percentages, dates, sample sizes, doses)
- **False solutions**: what the market already tried and was betrayed by
- **Symptom vocabulary**: the mundane ones AND the shameful ones — you need both registers
- **Signature scenes**: the recurring human moments that carry the emotion
- **Promise language**: what recovery sounds like in the brand's own words
- **Audience anchors**: phrases and facts the market already knows before reading

### 2. X-ray the source

Go through the source and mark every market-specific element. For each, note its **function** (what job the line does — diagnostic anchor, terminal stakes, buried truth, myth-bust…) and its **voltage** (which words carry the charge). Everything unmarked is skeleton and transfers verbatim — including instructional sections, process notes, and any line that happens to already fit the target market.

### 3. Build the vector map

Before writing a single transposed line, fill a two-column map across these standard vectors (skip any the asset doesn't use; add ones it does):

| Vector | What it is |
|---|---|
| **Villain** | The named enemy entity |
| **Mechanism** | The brand's physics of the problem, with its coinages |
| **Terminal event** | The market's irreversible worst case — its equivalent of death |
| **Pain language** | Symptoms, mundane and shameful; shame maps to shame |
| **Promise language** | What recovery looks and feels like |
| **Historical break** | When things changed, and the specific thing that changed them |
| **Buried truth** | The suppressed or ignored discovery — a specific document/study with numbers |
| **False solutions** | The betrayers already tried |
| **Audience anchors** | What they already know and hear |
| **Trigger words** | The charged vocabulary, mapped word-for-word |
| **Signature scenes** | The human moments; same emotional temperature, target market's cast |
| **Generational/social proof** | The outlier person, population, or era |

Rules for every mapping: same **function**, equal-or-greater **voltage**, grounded in the **target's actual claims**, one-to-one wherever possible. When a slot has no grounded twin in the target library, serve the function with the nearest grounded material and flag it as a judgment call in delivery — never quietly import the source market's facts, and never leave the slot limp.

### 4. Transpose

Now write, holding these invariants:

- **Count parity**: same number of hooks, blocks, list items, examples as the source.
- **Formatting mirror**: caps patterns, ellipsis style ("…" vs "..."), emoji, parentheticals (including clinical-Latin authority terms), whitespace and line breaks, separator markers — all reproduced exactly.
- **Sentence skeletons intact**: keep the grammatical shape and rhythm; swap the payload nouns/verbs inside it.
- **Certainty level intact**: an absolute claim stays absolute ("cannot exist" never becomes "may be less likely"). The source's confidence is part of the skeleton.
- **Word lists rebuilt honestly**: if the source extracts a list of charged words from its own examples, rebuild the list from words that actually appear in YOUR swapped examples.
- **Market-agnostic sections verbatim**: process instructions, format guidance, and any example that already targets the destination market pass through untouched.

### 5. Voltage audit — the anti-sanitization pass

Run this as a separate pass after transposing. The model's natural gradient is toward safety-blanket language, and it operates silently — you will not notice yourself doing it, which is why this is a checklist pass and not a vibe. Put source and output side by side and check every charged element against these tripwires:

- **Charged verb → clinical verb**: "strangling" becoming "restricting". Restore the verb.
- **Shameful symptom → polite euphemism**: "farts stink" becoming "digestive discomfort". The target equivalent must be equally embarrassing, not merely equally topical.
- **Named villain → vague forces**: "[the named company] changed everything" becoming "manufacturing changed". Keep the specific actor the target library names.
- **Absolute → hedge**: "cannot exist" becoming "is less likely". Hold the certainty.
- **Accusation → observation**: second-person stakes ("your wife stopped…") drifting to third-person ("some men notice…"). Keep it pointed at the reader.
- **Numbers → mush**: "9 out of 10" becoming "most samples". Specific numbers are voltage.
- **Conspiracy edge shaved**: "they buried it" becoming "it received limited coverage". Keep the edge the source had.
- **Added disclaimers**: qualifiers, caveats, or softeners the source never carried. Delete them.

Tie-break rule: when two grounded candidates both fit a slot, **take the more vicious one**. The ceiling is the source's register and the target library's own edge — not your comfort. Sanitization is sliding from a Level 3 opening (an emotional bomb that sets the stakes in the first line) back down to a Level 1 (a vague statement of the topic). Hold the level.

The honesty guard, so the two rails don't get confused: aggression is **register**, not fabrication. Voltage never licenses inventing a claim; grounding never licenses softening one.

### 6. Deliver

Save the transposed asset as its own file mirroring the source's exact format (same section order, separators, counts). Then report, in this order:

1. Where it's saved, with count parity confirmed ("20 hooks in, 20 hooks out")
2. The vector map you actually used, as a table
3. Judgment calls — every slot that had no grounded twin, and what you did about it
4. The double-pass offer: take the best or weakest swaps and push them back through at "make more vicious / Level 3"

## Boundaries

- **No source asset → wrong process.** MADLIBS ports proven material; writing fresh hooks or ads from a brief is a different job.
- **Not translation or localization.** MADLIBS moves an asset between markets, not between languages.
- **Not same-market editing.** Revising an asset for the market it already targets is iteration, not transposition.

The canonical worked pass was removed from this distribution copy — it contained a
specific brand's proprietary primer. Calibrate against your own source asset: put
source and output side by side, confirm count parity, and run the §5 voltage audit
on every swapped slot. The discipline is unchanged: minimum changes, zero voltage
