## Brief: answer 49 questions about how the app behaves plus three related asks

### Context

I am writing the member emails for Botterverse from outside the code. My only source is the member guide. Where the guide is silent or unclear I put a note in the email that says what I could not confirm. Each question below is one of those notes. Your answers decide whether I keep the wording as it is or change it.

### How to answer

- Answer from the code and not from the guide. If the guide and the code differ tell me.
- For each question give: **Yes**, **No** or **Different**, then one or two sentences, then the file or class you read.
- Where the answer is a label or a figure or a rule give the exact text or value.
- If the code does not decide it (for example a staff setting or a Stripe behaviour) say so and name who decides.
- Do not change any code. This brief asks for facts only.
- Keep the question numbers in your reply so I can match them.
